# SKAB 数据集使用说明

## 数据来源与用途

SKAB（Skoltech Anomaly Benchmark）是面向异常检测核心能力评估的公开工业时序基准数据集。当前项目使用它进行算法开发、回归测试、参数比较和校赛阶段演示，不把它当作联通企业现场数据。

来源：SKAB 官方仓库 `https://github.com/waico/SKAB`；数据集 DOI：`10.34740/KAGGLE/DSV/1693952`；项目仓库中的 `README.md` 和 `data/README.md` 为优先参考。

## 数据字段

官方 README 列出的字段包括：`datetime`、`Accelerometer1RMS`、`Accelerometer2RMS`、`Current`、`Pressure`、`Temperature`、`Thermocouple`、`Voltage`、`RateRMS`、`anomaly` 和 `changepoint`。

- `datetime`：采样时间戳。
- `anomaly`：点异常标记，表示该采样点是否被标记为异常点。
- `changepoint`：变化点标记，用于变化点/集体异常检测任务。它不是“整个故障区间”的通用标签，连续异常区间的解释应结合数据文件、评测定义和相邻样本完成。
- 其余字段：试验台上的振动、电流、压力、温度、热电偶温度、电压和流量等观测量。

## 项目使用流程

1. 读取 CSV，检查字段、时间戳、缺失值和数值类型。
2. 使用无标签或训练窗口建立基线，不能把测试文件中的标签当成在线输入。
3. 分别评估点异常检测和变化点检测，报告 F1、误报、漏报或适用的变化点指标。
4. 结合模型输出和标签做离线评估，再由诊断模块生成候选原因与验证步骤。
5. 将人工复核结果和实验参数写入报告，保证结果可复现。

## 结果解释边界

SKAB 的标签描述数据集评测任务，不等同于企业现场维修结论。即使模型在 SKAB 上识别出异常，也只能说明模型捕捉到了与标注相关的数据模式；实际设备根因还需要设备结构、工况、操作记录和现场复测支持。

SKAB 上得到的阈值、健康度分数和模型权重不能直接用于联通现场设备。接入真实数据后，应重新完成字段映射、工况划分、正常基线构建、阈值标定和现场验证。

## 使用边界与核验状态

- 文件数量和异常类型以项目本地 SKAB 版本及官方仓库说明为准，不在本文重复推断每个文件的物理故障类型。
- `valve1`、`valve2` 和 `other` 等目录名只能作为数据组织信息；具体异常含义必须以对应文件的官方说明或实验记录为依据。
- 本文不声称 SKAB 与任何特定国家标准“完全匹配”。标准术语只能作为辅助解释口径。
- 核验状态：数据集基础信息依据官方 README 整理；项目用途和限制为项目组定义。
