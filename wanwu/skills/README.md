# OpenClaw 式 Skill 清单

这里是“时察千机工业时序智能体”的能力契约，不是第二个智能体，也不替代万悟画布。
万悟聊天入口按照本清单选择 Skill，Skill 再调用已经导入的 FastAPI 工具；四个周期 Skill
由外部触发器自动运行，聊天只负责查询、解释和经过确认的人工动作。

## 调用规则

1. 默认使用只读工具。普通查询、异常解释和工单查询不得调用有副作用的工具。
2. 配置数据源、立即巡检、主动通知、SLA 督办和人工复检必须先取得明确确认。
3. 四个周期工作流属于部署时预授权的后台任务，允许按固定频率运行，但每次结果必须留下运行记录。
4. 工业数值计算、模型交叉验证、工单生成和通知幂等由 FastAPI 完成；模型只做按需解释。
   `explain_industrial_run` 只能读取已有成功任务的 `run_id`，按需执行 RAG 和一次辅助解释，
   不重新上传数据、不重复分析、不改变业务状态。
5. RAG 只能补充故障机理、验证步骤和处置规程，不能覆盖结构化算法证据或把候选原因变成确诊。

机器可读目录见 `wanwu/skills/catalog.json`。发布工作流或修改工具后，应同步检查目录、
`wanwu/agent_prompt.md` 和万悟中的工具描述。
