# 预测模型与验证方法

## 目标

预测模块负责把历史传感器序列转换为未来窗口、预测区间和可复核风险证据。它不直接调用
大模型，也不把原始 CSV 交给万悟。万悟只负责读取结构化结果并结合知识库解释。

## 候选模型

1. `persistence`：最近值持续模型，作为最低复杂度基线。
2. `moving_average`：指数平滑模型，适合平稳和缓慢变化信号。
3. `linear_trend`：局部线性趋势模型，适合单调漂移和退化过程。
4. `lag_ridge`：利用滞后值、差分、滚动均值、滚动标准差和趋势斜率的岭回归。
5. `time_frequency_ridge`：在滞后岭回归基础上加入主频、频带能量、谱熵和频域峰值。

## 无泄漏滚动回测

验证窗口位于序列末段，并被划分为多个连续折。每一折只能使用预测起点之前的数据，模型
预测该折后再移动到下一折。模型选择以 RMSE 为主、MAE 为辅，同时记录 MAPE、残差标准差
和残差绝对值 95% 分位数。

## 多步预测与稳定性保护

滞后模型采用递归预测：预测下一点后将其放回历史窗口，再预测下一点。系统逐步检查预测
是否为有限值、是否明显脱离历史尺度；失稳候选会被剔除，不参与最终模型分歧与区间计算。

## 不确定度与预警

95% 预测区间同时使用最优模型的滚动回测残差和候选模型分歧。预测越界但区间过宽、回测
误差较高时，只形成“需关注、人工复核”，不会直接判定高风险。多传感器同向风险会形成
设备级联动预警，并优先于低可信单点告警展示。

## 当前边界

该体系是可解释、可部署的工程模型底座，不是最终深度时序模型。后续应在固定数据划分上
加入跨文件训练的 TCN、PatchTST 或轻量 Transformer，并与当前五个模型进行统一指标对比、
消融实验、推理时延测试和企业数据验证。
