# 多传感器关系诊断

## 解决的问题

异常检测只能回答“何时出现异常”和“哪些测点贡献较大”。关系诊断进一步比较异常事件前后
的多传感器联动，形成“哪两个测点关系变化最大、哪个测点可能先变化”的排查线索。

## 计算过程

1. 从每个异常事件中选择主导传感器。
2. 截取事件前正常窗口和事件窗口。
3. 比较两个窗口中的 Pearson 相关系数。
4. 对事件窗口中的差分序列搜索最大互相关时滞。
5. 按相关性变化和时滞相关强度排序，输出重点关系和建议排查顺序。

## 输出含义

- `相关性变化`：异常前后两个测点线性联动变化程度。
- `最佳时滞`：两个差分序列联动最强时相隔的采样点数。
- `时滞解释`：将时滞符号转成“哪个测点领先哪个测点”的工程描述。
- `关系结论`：对最显著关系的简洁总结。

## 使用边界

相关性与互相关只能说明统计联动，不能单独证明物理因果。最终根因仍需结合设备拓扑、控制
指令、工艺机理、维修记录和现场检查确认。后续接入企业数据后，应加入设备测点拓扑约束，
减少不存在物理连接的传感器组合。
