# SKAB 实验结果与引用口径

本文件只保留校赛阶段可用于报告、PPT 和答辩的结论口径。逐文件原始结果、数据哈希和
运行环境信息以 `outputs/competition/` 下的实验产物为准，不应从历史临时报告中摘录数字。

## 当前权威实验批次

- 数据集：SKAB 公开工业时序数据集。
- 数据划分：1 个健康基线文件、17 个验证文件、17 个独立测试文件，共 35 个 CSV。
- 评测单位：按完整 CSV 文件划分，不拆分连续时序，避免训练、验证、测试之间的时序泄漏。
- 独立测试批次：`independent_test_20260813_164115.csv`。
- 运行清单：`SKAB_EXPERIMENT_RUN_MANIFEST.json`。
- 协议：`SKAB_EXPERIMENT_PROTOCOL.md`。

所有实验结论均为公开数据验证，不代表联通企业现场实测收益。

## 竞赛材料中的正确表述

1. 时频关系多路径检测器是当前 SKAB 独立测试中事件级 F1 最优的模型，并提供时域偏离、
   频域变化和多测点关系三类证据。
2. MAD 是低误报、低耗时的稳定告警基线，不应被描述为“落后模型”。
3. 线上默认模型采用时频关系多路径检测器；其冻结阈值和事件合并策略与当前实验协议一致。
4. 模型选择不只依据一个数值，同时考虑事件召回、误报事件、延迟、处理速度和可解释证据。
5. 企业数据接入后，必须重新建立健康基线、重新校准阈值，并以独立时间段复测。

## 可核验文件

- `outputs/competition/SKAB_EXPERIMENT_PROTOCOL.json`：数据文件哈希、划分和冻结参数。
- `outputs/competition/SKAB_EXPERIMENT_RUN_MANIFEST.json`：本次报告引用产物的哈希、环境和一致性校验结果。
- `outputs/competition/independent_test_20260813_164115.csv`：6 个检测器的逐文件独立测试记录。
- `outputs/competition/skab_competition_summary.md`：中文竞赛汇总，包含吞吐量和基线对照。
- `outputs/competition/FINAL_EVALUATION.md`：面向答辩的实验解读与边界说明。

## 复现方式

```powershell
.\scripts\run_skab_competition.ps1
```

该命令默认复用已冻结的独立测试产物并重新生成汇总、协议和运行清单；仅在需要重新调参与
重跑全量实验时使用：

```powershell
.\scripts\run_skab_competition.ps1 -Rerun
```
